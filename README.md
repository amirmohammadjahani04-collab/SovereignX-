# MyOS

![MyOS Desktop](screenshot.png)

## About

MyOS is a 64-bit graphical operating system built from scratch.

The goal of MyOS is to create a lightweight, modern desktop operating system with its own kernel, graphical interface, native applications, and system services.

## Features

- ✅ 64-bit kernel
- ✅ Limine bootloader
- ✅ BIOS boot support
- ✅ Custom framebuffer graphics
- ✅ Desktop environment
- ✅ Window manager
- ✅ GUI windows
- ✅ Mouse support
- ✅ Keyboard input
- ✅ Terminal application
- ✅ File manager
- ✅ Settings application
- ✅ Native GUI applications
