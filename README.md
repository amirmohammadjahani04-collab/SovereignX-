# SovereignX

### Your System, Your World 🌍

SovereignX is an independent 64-bit operating system.

## Features

- 64-bit kernel
- Graphical desktop
- Window manager
- Terminal
- File manager
- Networking
- Custom filesystem
- Security components
- M.C programming language
- Built-in applications

## About

SovereignX is an independent operating-system project focused on freedom, customization, and giving users control over their system.

## Status

🚧 SovereignX is under development.
